Pricing

VMBridge is sold as a one-time purchase of $9.99, with a 7-day full-featured free trial.

The price is $9.99 USD, paid once. It is not a subscription. A full-featured trial lasts 7 days from the first launch on that Mac.

Download DMG Buy for $9.99

Download the notarized DMG from this site. Buy opens the Polar checkout.

  • The trial clock is stored in license.json in Application Support. Deleting that file alone does not reset the trial: the earliest start is also kept in a hidden .trial-origin file and in the preference VMBridgeTrialStartedAt.
  • Setting the clock forward past the trial, then back, leaves the trial expired.
  • After a license key validates, the app keeps working for 14 days if the license server cannot be reached, as long as the key was active.
  • Keys are activated with Polar. The app does not ship an API token.
  • You need macOS 14 or later and Parallels Desktop Pro or Business.

The checkout is the VMBridge Polar link. A license key looks like VMB-<key>, can be active on 3 machines, and does not expire. VMBRIDGE_CHECKOUT_URL and VMBRIDGE_POLAR_ORGANIZATION_ID still override those defaults. A key is refused when its organization id does not match.
