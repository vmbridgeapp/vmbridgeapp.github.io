Pricing

VMBridge is sold as a one-time purchase of $9.99, with a 7-day full-featured free trial.

The intended price is $9.99 USD, paid once. It is not a subscription. A full-featured trial lasts 7 days from the first launch on that Mac.

Download DMG Buy for $9.99

The notarized DMG is not a file on this site. It ships with the GitHub release when a signed build is published. Buy opens the Lemon Squeezy checkout. The store is in test mode pending approval; this URL stays the same when the store is live.

  • The trial clock is stored in the macOS login Keychain and in a file in Application Support. Removing only one copy does not start the trial over.
  • Setting the clock forward past the trial, then back, leaves the trial expired.
  • After a license key validates, the app keeps working for 14 days if the license server cannot be reached, as long as the key was active.
  • Keys are activated with the Lemon Squeezy License API. The app does not ship a store API secret.
  • You need macOS 14 or later and Parallels Desktop Pro or Business.

The checkout is the VMBridge Lemon Squeezy store (slug vmbridge, store id 497255, product id 1437706, variant id 2244841). A license key can be active on 2 machines and does not expire. VMBRIDGE_CHECKOUT_URL, VMBRIDGE_LEMON_STORE_ID, VMBRIDGE_LEMON_PRODUCT_ID, and VMBRIDGE_LEMON_VARIANT_ID still override those defaults. A key is refused when its store id or product id does not match.
