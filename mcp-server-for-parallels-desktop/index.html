VMBridge / MCP server for Parallels Desktop

MCP server for Parallels Desktop

VMBridge is an MCP server that lets an AI agent drive a Parallels Desktop virtual machine.

An MCP server is the process an AI agent starts when it needs tools. VMBridge is that process for Parallels Desktop. The agent calls tools. VMBridge talks to Parallels. The guest's screen, keyboard, and mouse are what the agent uses.

What the server exposes

Screenshots come back with a coordinate map. OCR reads text on the screen. Clicks, typing, scrolling, and drags go through the Parallels Virtualization SDK, so the Mac does not ask for Accessibility or Screen Recording permission. Commands and files use Parallels Tools inside the guest.

  • Window list and focus, open an app or a URL, search files by name.
  • Start, stop, pause, suspend, resume, restart, clone, create, and delete a VM.
  • Snapshots, sign-in at the lock screen, clipboard, and an activity log.

Where it listens

On the Mac, the agent launches vmbridge over stdio. For an agent inside a VM, a daemon listens on 127.0.0.1 and on the Mac's address on the Parallels Shared and Host-Only networks. The default is not every interface on the Mac. A token for one VM is accepted only from that VM.

parallels-pro-mcp and guest-vm-agents start the same server.
