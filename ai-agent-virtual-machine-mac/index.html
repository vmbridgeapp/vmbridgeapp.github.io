An AI agent virtual machine on a Mac

VMBridge is how an AI agent gets a virtual machine on a Mac that already runs Parallels Desktop.

What do you need on the Mac?

macOS 14 or later, Parallels Desktop Pro or Business, and VMBridge. Guests need Parallels Tools for commands, files, and the clipboard. The screen, keyboard, and mouse work without Tools, which is how an agent can drive an OS installer.

Which guests?

Linux, Windows, and macOS guests that Parallels Desktop can run. Pass vm when more than one VM is on. An agent inside a VM can only see its own VM. Its token is refused from any other address, including a clone.

What stays on the Mac?

The menu-bar app shows when an agent is working. Settings hold the trial and the license key. Sign-in passwords stay in the login Keychain under "VMBridge sign-in". Files an agent sends you land in ~/Downloads/From VMs.
