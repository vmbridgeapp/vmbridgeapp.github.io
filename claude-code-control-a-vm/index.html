Use Claude Code to control a VM

Claude Code can control a Parallels Desktop VM through VMBridge's MCP server.

How do I connect Claude Code?

On the Mac, with VMBridge installed:

vmbridge connect claude-code

Quit Claude Code and open it again so it loads the server. The app's Agents screen does the same click. Codex and Cursor use vmbridge connect codex and vmbridge connect cursor. vmbridge connect list shows every client name.

What can Claude Code do in the VM?

It can look at the guest screen, click and type, run a command as the signed-in user or as admin when you allow it, and copy files. Per-VM switches decide what is allowed. Pause all agents stops every agent at once. The activity log records what ran. Passwords typed at the login screen are not written into that log.

Does the agent control the Mac?

The computer-use tools act on the virtual machine, not on the Mac's own desktop. An agent that you also allow to run shell commands on the Mac is a separate permission in that agent. VMBridge's switches are the boundary for the VM.
